# دمو کوچک کوهستان برفی ۱۹۴۲

- یک Volkswagen Kübelwagen دوره جنگ
- روستای کوچک برفی کنار کوه
- جاده آسفالت و جاده خاکی
- یک هواپیمای دشمن که خودرو را از بالا دنبال می‌کند و به آن شلیک می‌کند
- ۵ دنده؛ سرعت فقط به مقدار گاز و دنده وابسته است و با نگه‌داشتن گاز بی‌نهایت زیاد نمی‌شود
- کنترل: W گاز، S ترمز/معکوس، A/D فرمان، کلیدهای 1 تا 5 دنده
- Space فقط برای تست شلیک خودرو
- پروژه Godot است، نه APK.
- استاندارد Git: Branch اصلی = main، Remote = origin
